# Swiggy Sales Analysis Dashboard

## Overview

This project is an interactive Swiggy Sales Analysis Dashboard created using Power BI.
The dashboard helps analyze food delivery sales performance, customer ratings, order trends and state-wise sales distribution.

## Key Metrics

- Total Sales: ₹53.01M
- Average Rating: 4.34
- Average Order Value: ₹268.51
- Rating Count: 5.59M
- Total Orders: 197.43K
---
## Dashboard Features

  ### Sales Analysis
- Monthly Sales Trend
- Daily Sales Trend
- Weekly Sales Trend
### Food Category Insights
- Veg vs Non-Veg Sales Analysis
- Category-wise Filtering
### Location Analysis
- State-wise Sales Map
- Top 5 Cities by Sales
### Interactive Filters
- Month Filter
- Category Filter
- Restaurant Filter

---
## Insights from Dashboard
- Bengaluru generated the highest sales.
- Non-Veg food contributed more sales than Veg food.
- Sales remained consistent throughout most weeks.
- Q2 recorded the highest overall sales.

---
## Conclusion

This dashboard provides meaningful business insights into Swiggy sales performance and helps understand customer ordering patterns using interactive visualizations.
